# Python Uppercase Converter 

Un script interactivo escrito en Python que recibe una cadena de texto ingresada por el usuario y la convierte completamente a mayúsculas utilizando el método nativo `.upper()`.

## Características
* Interfaz interactiva por consola.
* Manipulación de cadenas utilizando métodos nativos de Python.
* Formato de salida claro con *f-strings*.

## Requisitos
* Python 3.x instalado en el sistema.
