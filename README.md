# Descripción

Un script interactivo escrito en Python que recibe una cadena de texto ingresada por el usuario y la convierte completamente a mayúsculas utilizando el método nativo `.upper()`.

## Conceptos Aplicados
* **Captura de Strings:** Uso de la función `input()` para recibir datos de texto por parte del usuario.
* **Manipulación de Cadenas:** Uso del método `.upper()` para transformar todos los caracteres alfabéticos a su equivalente en mayúsculas.
* **Formateo de Cadenas (f-strings):** Presentación del resultado formateado directamente en la salida de consola.
* **Salida de Datos:** Muestra del mensaje resultante mediante la función `print()`.
